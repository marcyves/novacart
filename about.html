About this shop

NovaCart is a fictional mid-size European D2C electronics brand. This GitHub Pages site is the live storefront for the IPAG MSc course WEB Tools (26M_ICT_559).

What you can do here

  • Run PageSpeed / Lighthouse on a URL you control as a class (compare homepage vs the Paid Social landing).
  • Check WAVE and Website Carbon.
  • Inspect the cookie bar (Accept only — on purpose).
  • Build UTM links that land on /c/paid-social.html.
  • Add to cart (browser only) and walk a demo checkout.

What this site is not

  • Not a real shop. No payment, no customer database.
  • Not OWASP Juice Shop. No security CTF.
  • Search Console / GA4 numbers for the case still come from the course pack — a new Pages site has no history.

The shop is measured in the instructor’s IPAG GA4 property (stream on this site). Case volumes in Moodle (March vs February) are still the teaching pack — this domain has no history yet.
